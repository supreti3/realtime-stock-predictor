# Real-Time Stock Market Predictor

This project is a real-time stock prediction dashboard built with Streamlit and FastAPI. It fetches live stock data, predicts the next closing price using a trained model, and displays top market gainers and losers in a rotating ticker interface.

## Features
- Real-time stock data from Yahoo Finance
- AI-based stock price prediction
- Interactive dashboard with Streamlit
- FastAPI backend for predictions
- Rotating ticker for top gainers and losers

## Technologies Used
- Python
- FastAPI
- Streamlit
- Scikit-learn
- Pandas
- yFinance
